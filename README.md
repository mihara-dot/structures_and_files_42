\# Лабораторная работа № 7 — Структуры и работа с файлами



\*\*Вариант:\*\* 24



\## Задача



Разработать программу для обработки сведений об участниках конференции.



Данные хранятся в текстовом файле. Каждая запись содержит фамилию, имя, отчество, учёную степень, тему доклада и продолжительность выступления.



Программа выводит сведения о докладчиках с заданной учёной степенью, вычисляет среднюю продолжительность их выступлений и находит самый непродолжительный доклад среди всех участников.



Для хранения данных используется структура `Participant` и вектор `vector<Participant>`.



\## Ввод данных



Программа запрашивает:

1\. Путь к входному файлу.

2\. Путь к выходному файлу.

3\. Учёную степень для поиска.



Входной файл содержит по одной записи на строку. Поля разделяются точкой с запятой.



Формат записи:



`Фамилия;Имя;Отчество;Степень;Тема доклада;Продолжительность`



Ограничение: не более 100 записей. Продолжительность должна быть положительным конечным числом.



\## Запуск



1\. Создать текстовый файл `input.txt` с данными участников.

2\. Запустить программу.

3\. Ввести путь к входному файлу.

4\. Ввести путь к выходному файлу.

5\. Ввести искомую учёную степень.

6\. Получить отчёт на экране и в выходном файле.



При ошибках чтения или некорректных данных программа сообщает об ошибке и прекращает обработку.
